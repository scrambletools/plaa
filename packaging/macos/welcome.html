What installing plaa changes

plaa goes into Applications. So that it can send what plays to AVB speakers and amplifiers without running as an administrator, installing it also:

  • adds you to the access_bpf group, creating it if it is not there yet, the same group Wireshark and triib use;
  • installs a launch daemon, run.plaa.bpf, which at every start lets that group open the Mac's packet capture devices (/dev/bpf*), so plaa can send and receive AVB's own network frames.

Nothing else on the system changes. To take plaa and the launch daemon out again, run sudo "/Library/Application Support/plaa/uninstall". The access_bpf group stays, as other apps may use it.
